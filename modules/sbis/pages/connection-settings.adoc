= Функции администратора

[#settings]
== Настройка подключения к системе Saby (СБИС)

Администратор должен настроить подключение к системе Saby (СБИС) в _Справочнике настроек операторов ЮЗДО_ {dv}, а также загрузить справочную информацию из системы Saby (СБИС).

. Запустите {wincl} от имени администратора {dv}.
+
Если {wincl} был открыт при установке Коннектора -- перезапустите.
+
. Откройте _Справочник настроек операторов ЮЗДО_.
+
.Справочник настроек операторов ЮЗДО
image::dictionary.png[Справочник настроек операторов ЮЗДО]
+
. В раскрывающемся списке *Оператор* выберите элемент "Saby (СБИС)".
. Нажмите кнопку image:buttons/three-dots.png[Три точки] в строке _Оператор_. Будет открыто окно настройки подключения к системе ЭДО.
+
.Параметры подключения к системе Saby (СБИС)
image::operator-settings.png[Параметры подключения к системе Saby (СБИС)]
+
. Укажите данные для подключения к системе Saby (СБИС)footnote:[Чтобы получить данные для подключения, необходимо провести процедуру подключения к API в личном кабинете Saby (СБИС) https://sbis.ru/help/ofd/api/api_cash/auth?ysclid=lssoos4lk9273340146[по инструкции]]:
+
* _ApiURL_ -- адрес сервера API системы Saby (СБИС), вводится вручную, значение можно изменить. +
** Стандартная точка подключения: `\https://online.sbis.ru`.
** Адрес тестового сервера: `\https://fix-online.sbis.ru`.
// tag::urls[]
* _DiskUrl_ -- URL файлового хранилища Saby (СБИС):
** Точка подключения к файловому хранилищу: `\https://disk.sbis.ru`.
** Точка подключения к тестовому файловому хранилищу: `\https://fix-disk.sbis.ru`.
// end::urls[]
+
// tag::params[]
* _AppClientId_ -- цифровой идентификатор (ID приложения). Требуется Saby (СБИС) для определения приложения. Идентификатор может быть найден в поле _ID приложения_, созданного подключения к Saby (СБИС).
* _AppSecret_ -- защищенный ключ. Используется вместе с идентификатором, чтобы сайт распознал приложение. Ключ находится в поле _Защищенный ключ_ созданного подключения.
// end::params[]
* _SecretKey_ -- ключ для авторизации внешних сервисов и приложений, которые работают в фоновом режиме. Ключ находится в файле, скачиваемом на вкладке "Общие настройки" созданного подключения.
+
. Нажмите *ОК* для сохранения настроек.
. В основном окне _Справочника настроек операторов ЮЗДО_:
+
--
.. Настройте справочник организаций.
.. Настройте справочник контрагентов.
--
+
Инструкция по выполнению данных действий приведена в руководстве по администрированию модуля _{em}_ в разделах "xref:admin:configure-directory.adoc[]" и "xref:admin:configure-partners.adoc[]".
+
****
По умолчанию массовая загрузка контрагентов выполняется с сервера, поэтому действуют правила серверного вызова, в т.ч. время ожидания. Чтобы избежать ошибки истечения времени ожидания при загрузке большого количества контрагентов из Saby (СБИС), в реестре на сервере приложений необходимо создать ключ `REG_DWORD 1` со значением `NoServerExtension` в ветке `HKEY_LOCAL_MACHINE\SOFTWARE\DocsVision\Edi\5.5`.
****

[#branch-code]
== Импорт контрагентов с учетом кода филиала

Коннектор к СБИС имеет особенность, при которой из нескольких записей с одними и теми же ИНН и КПП загружается только одна из них. Для общего импорта контрагентов или импорта отдельной организации из СБИС с одинаковым ИНН и КПП необходимо указывать также уникальный код филиала.

.Указание кода филиала
image::branch-code.png[Указание кода филиала]

Код филиала можно указать в Справочнике настроек операторов ЮЗДО: menu:Контрагенты[Организация > Дополнительно > Коды > Добавить код]. В поле "Название" укажите `Код филиала`, в поле `Значение` укажите сам код.

В справочнике желательно добавлять уникальные короткие названия для филиалов, чтобы их можно было отличать и выбирать в карточках, т.к., поле _Код филиала_ по умолчанию не выводится в разметках.
