= Журналирование бизнес-процессов ЭДО

Сообщения xref:ROOT:module-structure.adoc#inner-links[штатных бизнес-процессов ЭДО] записываются в журнал экземпляра бизнес-процесса и в журнал модуля {wf}.

[#bp-log]
== Журнал бизнес-процессов

Журнал содержит сообщения о выполнении функций экземпляра БП ЭДО. Для его просмотра откройте карточку экземпляра бизнес-процесса в {wincl}е и нажмите кнопку *Журнал процесса*.

Подробнее о просмотре и экспорте журнала см. в документации модуля {wf}, в разделе "xref:GBL-3610@workflow:user:bp-launch-monitor.adoc#bp-log[Просмотр журнала бизнес-процесса]".

[#config]
== Настройка журналирования

Журналирование сообщений БП ЭДО настраивается в конфигурационном файле модуля {wf}.

:module-service: модуля {wf}

+
. Измените параметры журналирования в секции `NLog`:
+
.Фрагмент конфигурационного файла модуля {wf}:
include::GBL-3610@workflow:admin:log.adoc[tags=workflow-nlog]

. Чтобы в журнал записывались информационные сообщения, установите значение `Info` для параметра `fileLogLevel` и/или `consoleLogLevel` в секции `NLog.variables`. При значении по умолчанию `Error` информационные сообщения не записываются.
. Сохраните изменения конфигурационного файла.
